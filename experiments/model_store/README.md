# Прототип хранения моделей (#74)

Изолированное исследование: Python Detector использует неизменные правила,
Rust хранит ru/en, префиксы, окончания и ngram-таблицы. В приложении этот модуль
не импортируется. Публичный протокол, конфиг и форматы поставляемых данных не меняются.

Rust использует только std. FFI — ctypes в одном Python-процессе, без помощника.
Преобразование регистра остаётся в Python, чтобы сохранить его Unicode-семантику.
Нормализация не добавляется; строки UTF-8, offsets в ABI — длины в байтах.
Float64 и порядок суммирования ngram сохраняются. Входной снимок ограничен
64 МиБ, строка — 64 КиБ; повреждённый снимок отклоняется. Указатель принадлежит
одному объекту Python: копирование запрещено, close идемпотентен, запрос и close
сериализованы. Передавать произвольные указатели в приватный ABI нельзя.

## Запуск на Linux

Нужны установленные Rust/Cargo, Python и pytest. Новые crates не загружаются.
Из корня checkout задайте `LAB` каталогом **вне Git**:

```sh
export LAB=/path/outside-checkout/model-store
mkdir -p "$LAB"
export CARGO_TARGET_DIR="$LAB/target"
cargo build --offline --release --manifest-path experiments/model_store/Cargo.toml
export WAYSWITCH_MODEL_STORE_LIB="$CARGO_TARGET_DIR/release/libwayswitch_model_store_experiment.so"
python -m pytest -q experiments/model_store
python experiments/model_store/compare.py --packs "$LAB/packs" --export
python experiments/model_store/compare.py --packs "$LAB/packs" --golden-root GOLDEN_CHECKOUT --output "$LAB/result.json"
```

`GOLDEN_CHECKOUT` — сохранённый checkout эталона #73 с
`tools/benchmark_focus.py` и `tests/fixtures/focus_golden_v1.json`.
Не меняйте его ожидания ради совпадения. В Windows те же команды работают
с переменными `$env:...` в PowerShell; библиотека называется
`wayswitch_model_store_experiment.dll`. Замеры RSS/PSS доступны только на Linux.
В обычном pytest проекта прототип не запускается: его тесты вызываются явно.

Сравниваются исходный gzip/JSON, Python на бинарном снимке и Rust на том же
снимке. Экспорт включает чтение исходных моделей; он измеряется отдельно,
не скрывается в цене нативной загрузки. Бинарный снимок не является новым
производственным форматом. Лицензии исходных данных сохраняются
([wayswitch/data/LICENSE](../../wayswitch/data/LICENSE)). Не добавляйте снимки
и необработанные отчёты в Git.

Готовность означает построение обоих ленивых индексов Python; у Rust они
строятся сразу. Загрузка повторяется в 20 свежих процессах с прогретым файловым
кэшем, поэтому это не disk-cold старт. p99 для коротких серий не выводится.
RSS/PSS включает весь измеряемый Python-процесс и Rust-библиотеку; это не RSS
полного демона с GUI. Память измеряется отдельно от времени. При 5000 персональных
словах сохраняются базовая и текущая модели, как в настоящем Detector.

Расширенная выборка содержит 7000 входов на текущих ru/en-моделях; она проверяет
идентичность, а не качество на отложенных данных. Все расхождения записываются;
их наличие или провал golden дают ненулевой код. В отчёте есть хеши данных,
исходников и загруженной библиотеки. FFI/строки входят в стоимость decide.
Не запускайте другие тесты или сборки на стенде во время измерения.

Ограничения: не переносится сам Detector, не проверяются новые языковые паки,
PyO3/отдельный IPC-процесс, пакетирование и запуск полного приложения с Rust.
Польза этого прототипа сама по себе не разрешает внедрение или изменение
120-миллисекундного ожидания раскладки.
