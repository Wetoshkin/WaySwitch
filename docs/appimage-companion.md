# Нативная служба из AppImage

В готовящихся исходниках после 1.1.4 кнопка инструкции службы в AppImage
открывает помощник установки. AppImage остаётся окном настроек: сам образ
не получает права администратора и не заменяет нативную службу.

Помощник показывает дистрибутив, менеджер пакетов, установленную версию и
кандидат из подключённых репозиториев. Широкого контракта совместимости
пока нет: требуется совпадение версии исходного приложения GUI и пакета;
ревизия упаковки может отличаться. Кандидат старше, новее или с неизвестной
версией — установка отключена. Получите совпадающие версии через их источники.

Для apt, ALT apt-rpm, dnf и zypper совместимый пакет передаётся системному
менеджеру в терминале после подтверждения. Команда закрепляет показанную
версию; перед запуском сведения повторно проверяются. Менеджер показывает
транзакцию, проверяет доверие репозитория и запрашивает авторизацию. При
отсутствии терминала команду можно скопировать. Помощник сам не скачивает
пакеты и не добавляет репозитории или ключи.

Для Arch показывается команда полного системного обновления; её следует
проверить и выполнить самостоятельно. Если пакет найден только в AUR через
установленный paru/yay, показывается команда с явным `aur/wayswitch`.
Перед её выполнением изучите PKGBUILD и все остальные файлы сборки.
Отсутствие подтверждённого пакета означает ручную инструкцию проверки
репозитория/AUR и обновления метаданных.

Если нативный `wayswitch` уже установлен, помощник не заменяет его пакетом
из другого источника. Обновляйте прежним менеджером либо командой
`wayswitch update --install`, если установленная версия её поддерживает.
Окно AppImage и служба обновляются отдельно.

NixOS получает [инструкцию модуля](nixos.md) и пересборки системы.
rpm-ostree получает инструкцию добавления слоёв и перезагрузки; произвольная
запись в `/usr` не предлагается. Flatpak сохраняет прежние инструкции на
основной системе, без доступа к устройствам и запуска команд основной системы.

Запуск терминала ещё не означает завершение установки. Прочитайте результат
пакетного менеджера. При ошибке или отмене используйте его штатное
восстановление: он мог изменить систему, универсального отката нет.
Пользовательские настройки помощник не меняет.

После успешной установки выйдите из сеанса и войдите снова для применения
udev и расширения GNOME. Повторите проверку в окне и выполните
`wayswitch doctor`. Когда готовы включить службу:

```sh
systemctl --user enable --now wayswitch
systemctl --user status wayswitch
```

Установка, включение службы и её проверенная работа — отдельные этапы.
Собственного привилегированного установщика (Phase B) в этой реализации нет.
