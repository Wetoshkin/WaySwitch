# Extra layouts Implementation Plan


**Goal:** Разрешить запуск с дополнительными источниками, выполняя исправления только ru/en.

**Architecture:** Полный список и системные индексы сохраняются. Общая политика языка и противоположной группы используется контроллером, запуском и диагностикой. Бэкенды подтверждают реальный переход до изменения текста.

**Tech Stack:** Python, pytest, libxkbcommon, существующие IPC/D-Bus/GTK; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-06-extra-layouts-design.md` (согласована 2026-11-06).

## Global Constraints

- Только ru/en; не считать любой латинский/кириллический источник поддерживаемым языком.
- Не менять системный список и индексы.
- Сохранить защиту паролей, фокуса, блокировки, прерывания и подтверждения раскладки.
- Работать самостоятельно по согласованной схеме; финальное независимое ревью.
- Не публиковать релиз/ответы, не включать чужие незавершённые изменения.

## Review Focus

- IME между ru/en: исходные индексы и невозможность использования его как английского.
- 5+ источников: карта не усекается и переключает исходный индекс.
- Несколько вариантов ru/en: используется текущий и первый противоположный.
- Внешняя смена во время отложенной замены/undo: никакого позднего вывода.
- Циклическое переключение: промежуточные события, потерянное подтверждение, недостижимая цель не приводят к удалению текста.
