# Архитектура WaySwitch

WaySwitch исправляет русско-английскую раскладку в сеансе Wayland.
Демон получает события клавиатуры через evdev, сравнивает варианты слова
по словарям и символьным триграммам, переключает раскладку и перепечатывает
слово. GTK4/libadwaita-интерфейс общается с демоном по D-Bus.

## Путь события

1. `keys.py` обнаруживает устройства, обрабатывает подключение и потерю событий.
2. `buffer.py` хранит нажатия с учётом модификаторов; `gesture.py`
   распознаёт ручное исправление.
3. `controller.py` проверяет состояние сессии, поля ввода и исключения,
   затем вызывает `detector.py`.
4. `keymap.py` декодирует нажатия в обеих раскладках. `detector.py`
   использует словари и `ngram.py`, чтобы выбрать исправление.
5. `actuator.py` строит и исполняет план: смена раскладки, удаление старого
   слова, печать нового. При отправке отдельных клавиш обнаруженный физический
   ввод прерывает дальнейшие изменения. Частичная замена не считается успешной
   и не повторяется; атомарность с физической клавиатурой не гарантируется.
   В Writer доступна замена проверенного диапазона через `editable.py`.
6. `dbus_service.py` сообщает интерфейсу о состоянии и исправлениях.

## Модули

| Область | Файлы |
|---|---|
| Конфигурация и исключения | `wayswitch/config.py` |
| Клавиши, раскладки, буфер | `keycodes.py`, `keymap.py`, `buffer.py`, `gesture.py` |
| Решение и исполнение | `ngram.py`, `detector.py`, `controller.py`, `actuator.py` |
| Устройства и сеанс | `keys.py`, `session.py`, `a11y.py`, `daemon.py` |
| Переключение раскладки | `wayswitch/backends/` |
| D-Bus и команды | `dbus_service.py`, `cli.py`, `doctor.py` |
| Окно, первый запуск, панель | `wayswitch/gui/`, `panel.py` |
| Выделение и преобразования | `selection.py`, `textops.py` |
| Обновления и звук | `updates.py`, `sound.py` |
| GNOME Shell | `extension/wayswitch@wetoshkin.github.io/` |
| Установка и пакеты | `packaging/`, `tools/stage.sh`, `tools/build_*.sh` |

Если каталог не указан, Python-модуль находится в `wayswitch/`.

## Интеграции с рабочим столом

- GNOME: расширение Shell, IBus и резервное сочетание клавиш.
  Предпочтительный путь — расширение: оно сообщает текущую раскладку и
  позволяет печатать символы. IBus зависит от конфигурации сеанса.
- KDE Plasma 6: интерфейс раскладок KWin через D-Bus и виджет панели.
- Sway и Hyprland: IPC композитора; панель подключается через Waybar.
- Umbriel: IPC композитора с подтверждением раскладки; перед вводом отдельно
  проверяются активность обычного окна и свежие свойства сессии logind.
  Это не заменяет проверку защищённого поля через AT-SPI.
- Среды на labwc/Wayfire: сочетание XKB и отслеживание переключений.
  Текущее состояние раскладки может быть недоступно, поэтому этот путь
  имеет дополнительные ограничения.

Идентификаторы `io.github.Wetoshkin.WaySwitch` и `wayswitch@wetoshkin.github.io` — часть
интерфейса приложения и расширения, а не контактные адреса.

## Границы и данные

Демон не захватывает клавиатуру и не требует запуска от root. Доступ к
устройствам выдаётся правилом udev пользователю активного сеанса. Этот
доступ получают и другие процессы того же пользователя.

Блокировка сеанса останавливает исправления. Определение защищённых полей
и исключений по приложениям зависит от сведений, доступных в окружении;
оно не заменяет паузу при вводе чувствительных данных.

История исправлений в окне хранится в памяти. Настройки и исключения
сохраняются в `~/.config/wayswitch/`. `--verbose` и `dry-run` могут выводить
введённый текст. Проверка обновлений обращается к GitHub API, не передавая
текст; её можно отключить в настройках.

## Разработка

Чистые модули не импортируют `gi` и `evdev` на уровне модуля. Зависимости
платформы загружаются внутри соответствующих реализаций. Это позволяет
проверять логику на Windows и Linux без запущенного рабочего стола.

Словари и триграммы собираются командой `python tools/build_data.py`.
Источник и лицензия данных указаны в `wayswitch/data/LICENSE`; лицензию
данных нельзя заменять лицензией кода.

Команды проверки — в [руководстве для участников](../CONTRIBUTING.md),
ручные сценарии — в [чек-листе Wayland](testing-vm.md).
