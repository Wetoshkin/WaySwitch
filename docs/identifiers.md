# Идентификаторы приложения и обновление

WaySwitch использует пространство имён своего GitHub-проекта:

| Компонент | Идентификатор |
|---|---|
| Демон D-Bus | `io.github.Wetoshkin.WaySwitch` |
| Расширение D-Bus | `io.github.Wetoshkin.WaySwitch.Shell` |
| Окно настроек | `io.github.Wetoshkin.WaySwitch.Settings` |
| Flatpak | `io.github.Wetoshkin.WaySwitch.Gui` |
| AppImage | `io.github.Wetoshkin.WaySwitch.AppImage` |
| Расширение GNOME | `wayswitch@wetoshkin.github.io` |
| Виджет KDE | `io.github.Wetoshkin.wayswitch` |

Это локальные технические идентификаторы, а не адреса почты или серверов.
Настройки, исключения и звуки по-прежнему находятся в `~/.config/wayswitch`.
Имя пользовательской службы `wayswitch.service` и команды CLI не меняются.

## Обновление нативной установки

На обычных системах установщик одной командой обновляет программу, убирает
прежние пользовательские расширения по собственным метаданным WaySwitch
и перезапускает службу. На Bazzite и других атомарных системах новый помощник
доступен после загрузки нового развёртывания; выполните его после перезагрузки.
Старое пространство имён не обслуживается через дополнительные D-Bus-псевдонимы.
При первом запуске нативного окна автозапуск значка переносится на новое имя;
отключённый автозапуск не включается. Чужие файлы и ссылки не переносятся.
Записи с дополнительными условиями запуска, нестандартной командой или задержкой
автоматически не изменяются. Такие пользовательские ярлыки обновите вручную,
сохранив их условия; универсальное слияние настроек автозапуска не выполняется.

При ручной установке DEB/RPM/Arch, а также после перезагрузки Bazzite и других
атомарных систем выполните от обычного пользователя:

```sh
python3 /usr/share/wayswitch/migrate.py
systemctl --user restart wayswitch
```

Для установки из исходников помощник находится в
`/usr/local/share/wayswitch/migrate.py`. Он удаляет прежние расширения только
при совпадении имени WaySwitch, URL проекта и UUID с именем каталога.
Системные файлы пакета заменяются пакетным менеджером.

В GNOME выйдите из сеанса и войдите снова, затем включите новое расширение:

```sh
gnome-extensions enable wayswitch@wetoshkin.github.io
systemctl --user restart wayswitch
wayswitch doctor
```

Новый код расширения не появляется в уже работающем GNOME Shell после простого
копирования файлов. Закреплённый старый ярлык нужно заменить новым. В KDE
удалите прежний виджет с панели и добавьте WaySwitch заново. Правила окон Sway
и Hyprland обновите по фрагментам из окна настроек.

## Flatpak и AppImage

Новый Flatpak ID считается отдельным приложением. Установка нового bundle
с `--or-update` сама по себе не удаляет прежнее окно. Посмотрите список:

```sh
flatpak list --user --app --columns=application,name
```

Закройте прежнее окно WaySwitch и удалите его через менеджер Flatpak, сохранив
данные приложения (без `--delete-data`). После проверки SHA256 установите новый
`WaySwitch-Settings.flatpak` из того же релиза. Служба хоста обновляется отдельно;
общие настройки WaySwitch сохраняются. Старые разрешения D-Bus Flatpak на новый
ID автоматически не переносятся.

Для AppImage закройте прежнее окно, проверьте SHA256SUMS и замените файл.
Если был создан ярлык вручную, обновите его. Переносимое окно не меняет
автозапуск нативной установки.
