## Что проверить на живой GNOME (VM)

- [ ] **Первым:** `ibus engine xkb:ru::rus` переключает раскладку Shell (спец. 13.1).
      Гипотеза: `set_global_engine` может не переключать xkb-группу GNOME Shell —
      тогда авторежим только с расширением (`prefer = "shell"`)
- [ ] после перелогина `systemctl --user status wayswitch`: сервис стартует внутри
      графической сессии, в логе бэкенд `shell`/`ibus`, не `hotkey`
- [ ] роллинг (пробел нажат до отпускания последней буквы) — слово исправляется,
      без «исправление отменено: зажата физическая клавиша»
- [ ] нажатие клавиши на той же клавиатуре во время перепечатки прерывает её
- [ ] реальный `settle_ms` для IBus-пути
- [ ] расширение: `notify_keyval` печатает кириллицу при латинской раскладке
- [ ] трей виден в Ubuntu (AppIndicator)
- [ ] адресная строка браузера с автодополнением
- [ ] `tests/e2e_vm.py` проходит
- [ ] второй запущенный экземпляр демона завершается кодом выхода 3, а не падает
- [ ] предупреждение о нехватке прав на устройство ввода выводится один раз, не на каждое событие
- [ ] `wayswitch gui` открывает окно настроек
- [ ] тройной Shift после автоисправления: фраза перепечатывается в раскладке, которую выбрал двойной Shift
