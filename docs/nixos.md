# NixOS

Выражения в `packaging/nix/` собирают текущую копию исходников. Для них нужен
актуальный Nixpkgs с `lib.fileset` и `wrapGAppsHook4`. Это отдельная упаковка:
запускать `packaging/install.sh` на NixOS не требуется.

## Сборка пакета

Из корня проекта:

```sh
nix-build -E 'let pkgs = import <nixpkgs> {}; in pkgs.callPackage ./packaging/nix/package.nix {}'
./result/bin/wayswitch version
./result/bin/wayswitch doctor
```

Пакет включает PyGObject, GTK 4, libadwaita и IBus typelibs. Обёртки добавляют
`gsettings` в `PATH` и задают пути
для `libxkbcommon` и `libwayland-client`, а `XKB_CONFIG_ROOT` по умолчанию указывает
на данные `xkeyboard-config` из Nix store. Явно заданный `XKB_CONFIG_ROOT`
сохраняется. Python-код, словари, лицензии и конкретные файлы интеграции входят
в исходник через `lib.fileset`; рабочие журналы, `build/`, `.git`, файлы агентов
и конфигурация владельца в этот исходник не включаются.

Сам пакет не меняет права устройств и не включает системные службы. Для этого
нужен модуль ниже.

## Системный модуль

Добавьте в конфигурацию NixOS, заменив путь на свою копию проекта:

```nix
{
  imports = [ /path/to/WaySwitch/packaging/nix/module.nix ];
  services.wayswitch.enable = true;
}
```

Модуль устанавливает пакет, загружает `uinput`, подключает существующее правило
udev и включает AT-SPI через D-Bus. Доступ к устройствам выдаётся активному
локальному сеансу через `uaccess`; членство в группе `input` не требуется.
В dconf добавляется значение по умолчанию `toolkit-accessibility=true`.
Пользовательское значение имеет приоритет. После применения конфигурации
перезайдите в графический сеанс и перезапустите проверяемые приложения.

Служба работает от пользователя и запускается вместе с
`graphical-session.target`. Включение через модуль действует для графических
сеансов пользователей системы. Управляйте постоянным автозапуском в конфигурации
NixOS; переключатель автозапуска в окне настроек не отменяет декларативное
`wantedBy`. Для немедленной остановки доступно:

```sh
systemctl --user stop wayswitch
```

Пакет содержит расширение GNOME Shell; в GNOME его нужно включить обычным
способом. Другие среды используют свой поддерживаемый бэкенд.

## Сеанс Umbriel

Композитор должен поднять `graphical-session.target` и передать актуальное
окружение в пользовательский systemd. После запуска композитора, когда его
сокет уже существует, из терминала этого сеанса:

```sh
systemctl --user import-environment WAYLAND_DISPLAY XDG_CURRENT_DESKTOP XDG_SESSION_TYPE UMBRIEL_SOCKET
systemctl --user start graphical-session.target
systemctl --user restart wayswitch
wayswitch doctor
journalctl --user -u wayswitch -b
```

Используйте эти команды в механизме запуска сеанса своего композитора; при выходе
он должен останавливать `graphical-session.target`. Сокет из прежнего сеанса
не подходит. Если `UMBRIEL_SOCKET` не задан композитором, WaySwitch ищет его
в каталоге времени выполнения пользователя.

В Umbriel должны быть настроены русская и английская раскладки. Его IPC
подтверждает текущую группу, но не передаёт XKB options и переназначения отдельных
клавиатур. Произвольные различия раскладок физических устройств и `uinput`
этой интеграцией не подтверждаются. Без достоверного обычного поля AT-SPI
автоисправление продолжает ждать; наличие сокета композитора не заменяет
проверку защищённого ввода.

Если установка прошла проверки, а слова исправляются через раз, соберите
[отчёт из проблемного поля](../README.md#отчёт-о-пропущенном-исправлении)
командой `wayswitch doctor --delay 5`. Строка об автоисправлении показывает
настройку запущенного демона. Если она выключена, проверьте значение
`general.auto_correct` в конфигурации Home Manager, примените изменение
и перезапустите службу командой `systemctl --user restart wayswitch`.

Для охраны ввода также нужна активная графическая сессия, зарегистрированная
в logind. Сам запуск `graphical-session.target` такую регистрацию не создаёт.
Перед каждым вводом проверяются состояние композитора и свежие `Active` /
`LockedHint` выбранной сессии. При неизвестном состоянии блокируются и автоматика,
и ручной жест. После потери владельца logind перезапустите службу WaySwitch.
Запуск композитора прямо из незарегистрированного графического сеанса пока
не подтверждён этой интеграцией.

## Проверка

Выражение содержит проверки импорта Python-зависимостей, GTK/Adw/IBus typelibs,
сборки карты `us,ru` через `libxkbcommon` и установленной команды `version`.
Они выполняются при настоящей сборке Nix. Для проверки модуля используйте
`nixos-rebuild build`, затем проверяйте службу, права устройств и обычные/
парольные поля в отдельном живом графическом сеансе.

Выражение и системный модуль проверены настоящим Nix; пакет собран в отдельном
непривилегированном хранилище на Linux. Проверки установки включают запуск
обёрнутой команды `doctor` с пустым системным `PATH` и memory backend GSettings.
Живой графический сеанс NixOS пока не проверен. Эти проверки не подтверждают
совместимость всех приложений или переназначений клавиатуры.

Помощник AppImage направляет установку службы NixOS к этому модулю и
пересборке системы. Кнопки записи в `/usr` или запуска обычного установщика
для NixOS нет. Версия GUI и нативного пакета проверяется отдельно.
