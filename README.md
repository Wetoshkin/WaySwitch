# WaySwitch

**Русский** · [English](README.en.md)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![Platform: GNOME Wayland](https://img.shields.io/badge/platform-GNOME%20Wayland-orange.svg)](https://wayland.freedesktop.org/)

WaySwitch чинит слово, набранное не в той раскладке (`ghbdtn` вместо
«привет»), сразу же, на пробеле — без горячих клавиш и без переключения
раскладки вручную. На X11 такие утилиты давно есть; на Wayland компоситор
намеренно не даёт программе ни слушать чужую клавиатуру, ни подделывать
ввод через окна — общего с X11 API здесь нет. WaySwitch обходит это,
работая на уровень ниже графического стека: читает события клавиатуры
напрямую из `/dev/input` (`evdev`) и печатает через виртуальную клавиатуру
ядра (`uinput`), так что композитору всё равно, GNOME это, Wayland или что
угодно ещё с теми же интерфейсами ядра. Демон никогда не захватывает
клавиатуру устройства — если он зависнет, клавиатура продолжит работать
как обычно.

## Как это выглядит

- Набрали `ghbdtn ` (латиницей вместо русской раскладки) — на пробеле само
  становится `привет `, раскладка переключается вместе со словом.
- Начали адрес не в той раскладке — `реезыЖ..` — WaySwitch узнаёт схему
  URL и чинит её сразу, не дожидаясь пробела.
- Слово исправилось не то, которое нужно, или вручную нужно поправить то,
  что автоисправление пропустило, — двойной Shift чинит последнее слово,
  тройной (третий тап следом за двойным) — всю набранную фразу.
- Автоисправление сработало ошибочно — тот же двойной Shift в течение
  нескольких секунд после него откатывает слово обратно и запоминает его
  как исключение: второй раз WaySwitch его не тронет.

## Установка

### Debian/Ubuntu: .deb-пакет (рекомендуется)

```bash
url=$(curl -s https://api.github.com/repos/Wetoshkin/WaySwitch/releases/latest | grep -o 'https://[^"]*\.deb' | head -1)
wget "$url"
sudo apt install ./wayswitch_*.deb
```

Пакет архитектурно-независимый (`all`); зависимости (`python3-evdev`,
`python3-gi`, GTK4/libadwaita, IBus, `libxkbcommon0`, `udev`) подтягивает
`apt` сам. Все релизы — на странице
<https://github.com/Wetoshkin/WaySwitch/releases>.

Дальше от имени обычного пользователя:

```bash
# перелогиньтесь — правила udev применяются к новому сеансу
wayswitch doctor
systemctl --user enable --now wayswitch
wayswitch-gui
```

Необязательно: `gnome-extensions enable wayswitch@siberia.ru` (после
перелогина) — расширение GNOME Shell ставится пакетом системно и даёт
демону точное состояние раскладки и мгновенную перепечатку без ожидания
сигнала о смене раскладки; без него WaySwitch работает через IBus и
ждёт `settle_ms` перед печатью.

### Из исходников / Fedora

```bash
git clone https://github.com/Wetoshkin/WaySwitch.git wayswitch
cd wayswitch
sudo packaging/install.sh
```

Скрипт ставит системные пакеты, копирует код в `/usr/local/lib/wayswitch`,
кладёт правило udev, systemd user-юнит и расширение GNOME Shell в профиль
вызвавшего пользователя (`sudo` от обычного пользователя, не от root).
Дальше — те же три шага, что и после `.deb`. На Debian/Ubuntu предпочтителен
пакет выше; этот путь — для Fedora и сборки из исходников.

### Удаление

```bash
sudo apt remove wayswitch          # если ставили .deb
sudo packaging/uninstall.sh        # если ставили из исходников
```

Конфигурация пользователя (`~/.config/wayswitch`) при удалении не трогается.

## Использование

| Жест | Действие |
|---|---|
| Двойной Shift (второй тап в пределах 0,4 с) | исправить последнее слово; при пустом буфере — просто переключить раскладку |
| Тройной Shift (третий тап следом за двойным) | исправить всю фразу в раскладке, которую выбрал двойной Shift |
| Двойной Shift в течение `undo_window_sec` после автоисправления | откатить слово и запомнить его как исключение |

Жесты не работают, пока экран заблокирован или демон на паузе. На время
ввода пароля поставьте демон на паузу — он не видит текст в полях
паролей, но безопаснее не полагаться на это и не пытаться там ничего
исправлять.

| Команда | Действие |
|---|---|
| `wayswitch run [--verbose] [--dry-run] [--config PATH]` | запустить демон |
| `wayswitch dry-run` | демон в режиме наблюдения (verbose, без действий) |
| `wayswitch doctor` | диагностика окружения |
| `wayswitch devices` | список устройств ввода |
| `wayswitch pause` / `resume` | пауза/возобновление по D-Bus |
| `wayswitch fix` | исправить последнее слово по D-Bus |
| `wayswitch status` | состояние демона |
| `wayswitch gui` | открыть окно настроек |
| `wayswitch version` | версия |
| `wayswitch-gui [--tray]` | настройки; `--tray` — сразу в трей, без окна |

Значок в трее открывает меню: переключатель автоисправления, пауза/
возобновление, «исправить последнее слово», настройки, выход.

## Настройка

`~/.config/wayswitch/config.toml` (создаётся при первом сохранении из GUI
или руками):

```toml
[general]
auto_correct = true           # включено ли автоисправление на пробеле
sensitivity = "normal"        # conservative | normal | aggressive
phrase_timeout_sec = 8.0      # пауза между словами, после которой фраза для тройного Shift обнуляется (1..300)
undo_window_sec = 5.0         # сколько секунд после автоисправления двойной Shift ещё откатывает слово (0..60)

[gesture]
manual = "double_shift"       # double_shift | pause_key | none
pause_hotkey = ""             # клавиша паузы, например "scroll_lock" (пусто — не назначена)

[typing]
settle_ms = 30                # запас после сигнала о смене раскладки на пути IBus, мс (0..2000)
key_delay_ms = 0              # задержка между отправляемыми клавишами, мс (0..100)

[backend]
prefer = "auto"               # auto | shell | ibus | hotkey
```

`sensitivity` регулирует порог: `conservative` реже ошибается, но и реже
чинит короткие/редкие слова; `aggressive` — наоборот.

`~/.config/wayswitch/exceptions.txt` — слова, которые никогда не
исправляются автоматически (по слову в строке, регистр не важен);
пополняется откатом жестом или из GUI.

## Как это работает

1. `evdev` слушает клавиатуры напрямую по `/dev/input/event*`, без захвата
   устройства и без прав root: правило udev с тегом `uaccess` выдаёт доступ
   пользователю активного сеанса, никаких групп добавлять не нужно.
2. Буфер копит коды клавиш текущего слова и фразы, отдельно отслеживает
   Shift/CapsLock.
3. На пробеле детектор декодирует нажатия двумя способами — в текущей
   раскладке и в альтернативной — по таблицам `libxkbcommon`, построенным
   из настоящих раскладок пользователя (не зашитых QWERTY/ЙЦУКЕН).
4. Решение «оставить» или «исправить» принимается по словарю и модели
   символьных триграмм, с стоп-правилами для цифр, смешанных алфавитов,
   camelCase, путей/URL и коротких слов вне словаря.
5. Для исправления строится план: N×Backspace, переключение раскладки
   через выбранный бэкенд (расширение GNOME Shell → IBus → хоткей как
   резерв) и перепечатка символов через `uinput`.
6. Ранний триггер отдельно ловит начало URL (`http://`, `https://`,
   `ftp://`), набранное не в той раскладке, — не дожидаясь пробела.
7. Жесты (двойной/тройной Shift) и откат с запоминанием слова в
   исключениях работают поверх того же плана исполнения; пока экран
   заблокирован или демон на паузе, ничего не происходит.

Качество детектора на отложенной части словаря (не участвовавшей в
обучении): ru — полнота 96,5 %, ложные срабатывания 0,07 %; en — полнота
96,8 %, ложные срабатывания 0,07 %.

## Требования

- GNOME 46–49 на Wayland.
- Ровно две раскладки ввода: одна `ru*`, одна латинская.
- Ubuntu 24.04+ или Fedora 40+.
- Python 3.11+.

## Статус и ограничения

WaySwitch v2 — **альфа**, полностью переписанная с нуля. Вся логика
покрыта юнит-тестами и проверена на Windows и в CI (Linux), но ни разу не
запускалась на живом GNOME — чек-лист первого запуска в VM:
`docs/testing-vm.md`. Известные ограничения:

- Демон не видит текст в полях паролей — на время ввода пароля ставьте
  его на паузу.
- Поля с автодополнением (например, адресная строка браузера) могут вести
  себя неожиданно при перепечатке.
- Если исправление прервано на середине (физическое нажатие клавиши во
  время перепечатки), уже отправленные символы не откатываются — попытка
  «починить» вслепую только усугубила бы расхождение с экраном.
- Правило udev `uaccess` даёт чтение событий клавиатуры любой программе
  текущего пользователя, не только WaySwitch, — это цена схемы на `evdev`.
- Поддерживается только GNOME; KDE и Sway/Hyprland — в планах.

## Разработка

```bash
pip install pytest ruff
python -m pytest -q
python -m ruff check .
```

Два теста `keymap.py`, завязанных на настоящий `libxkbcommon`
(`tests/test_keymap_xkb.py`), пропускаются на Windows и выполняются в CI
(GitHub Actions, `ubuntu-latest`). Словарные данные пересобираются
командой `python tools/build_data.py`. Пакет `.deb` собирается на Linux
командой `bash tools/build_deb.sh`; релизы выпускаются по тегу `vX.Y.Z`,
совпадающему с версией в `pyproject.toml`.

## Roadmap

- Бэкенд для KDE Plasma и IPC-бэкенды для Sway/Hyprland.
- Определение полей паролей и активного приложения через AT-SPI — на
  любом окружении, не только через эвристики GNOME.
- Исправление уже выделенного текста через буфер обмена/портал.
- Третьи языки как подключаемый пакет словаря и триграмм.
- Привилегированный helper вместо широкого правила `uaccess` на
  клавиатуры.
- `.rpm`-пакет (Flatpak невозможен: нужен прямой доступ к `/dev/input`).
